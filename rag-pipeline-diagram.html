📥 Indexing (happens once / periodically)
1
Ingest Load from any source (files, APIs, crawlers)
2
Parse & Clean Extract text, keep structure, remove noise
3
Chunk 500–1000 tokens typical, with overlap
4
Embed OpenAI / Cohere / open-source models
5
Store Pinecone, Qdrant, Chroma, pgvector…
⚡ Querying (every user question)
1
Receive question Optional: rewrite / expand query
2
Embed the question Must use the exact same model
3
Similarity search Vector search ± keyword (hybrid)
4
Re-rank (recommended) Cross-encoder for higher precision
5
Generate answer LLM + retrieved context + good prompt

Key Insight

RAG quality is usually limited more by retrieval (chunking + embeddings + search) than by the LLM itself. A weaker model with excellent retrieved context often beats a stronger model with poor context.
